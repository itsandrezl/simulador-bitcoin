# Como contribuir

O processo completo está no [Plano de GCS](docs/gcs/plano-gcs.md). Resumo:

1. Abra uma Issue de solicitação de mudança.
2. Crie uma branch a partir de `develop` (`feature/...`, `fix/...`, `docs/...`).
3. Use Conventional Commits (`feat:`, `fix:`, `docs:`...).
4. Abra um Pull Request com o template e aguarde CI verde e aprovação do par.
5. Não há push direto em `main`.
